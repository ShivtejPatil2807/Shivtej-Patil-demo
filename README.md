### What is GitHub?
* **GitHub is an online platform where developers can store, manage, share, and collaborate on their code and projects.**

* **It uses Git, a version control system, to keep track of changes made to files and projects.**

### What is Git?
* **Git is a version control system that helps developers track changes in their code.**

**With Git, we can:**

* **Save different versions of our project**
* **Track Changes**
* **Go back to previous version**
* **Work on projects with other developers**
* **Create branches for new features**

### What can we do with GitHub?

**GitHub allows us to:**

* **📂 Store projects in repositories**
* **📝 Manage and edit code**
* **🔄 Track project changes**
* **🌿 Create branches**
* **🔀 Merge changes**
* **👥 Collaborate with other developers**
* **🐛 Report and manage issues**
* **📖 Create project documentation using README files**

### Basic Git Commands

* git init 
* git add . 
* git commit -m "Initial commit" 
* git branch -M main 
* git remote add origin <repository-url> 
* git push -u origin main
